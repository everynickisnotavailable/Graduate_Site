Глава 1 — Цель проекта

Я делаю рабочий веб-сервис «цифровой двойник» инвестиционных проектов Гатчины: постоянно доступный и расширяемый инструмент для оценки и сравнения проектов. Пользователь попадает на карту города с отмеченными проектами, кликает по маркеру и видит карточку проекта с описанием, ссылками на документы, контактами и встроенным финансовым виджетом. В виджете можно менять параметры и получать ключевые экономические показатели и графики. Также реализованы удобные фильтры и режим сравнения нескольких проектов. В итоге цель — дать инвестору быстрый и удобный инструмент для отбора и первичной оценки проектов без необходимости «перекопать» стопки бумажных паспортов.

Глава 2 — Функциональный набор результата

В результате будет реализовано: интерактивная карта с маркерами проектов; карточка проекта с основными данными, документами и контактами; финансовый калькулятор с возможностью менять входные параметры; динамический график годовых и накопленных денежных потоков; фильтры для отбора и отображения проектов на карте; возможность пометить несколько проектов и открыть сравнительный экран с таблицей ключевых KPI и мини-графиками; пресеты сценариев (пессимистичный/базовый/оптимистичный); импорт/экспорт данных в JSON для загрузки и резервного копирования; опциональная выгрузка краткого профиля проекта в PDF.

Глава 3 — Расчёты

Финансовая часть есть и будет включать стандартные метрики — NPV, IRR, срок окупаемости и другие KPI по требованию. Конкретные формулы и нюансы расчётов предоставляет команда финансистов; моя задача — корректно перевести их в код. Для прототипа расчёты могут выполняться на стороне клиента (в браузере) для быстрой обратной связи; при необходимости и по мере роста проекта я перенесу вычислительную логику на серверную сторону, сохранив формат данных и API, чтобы не ломать интерфейс.

Глава 4 — Технологии и их роль (для локальной разработки)

Фронтенд: Vue.js для интерфейса и управления состоянием, Chart.js для графиков, Яндекс.Карты JS API для интерактивной карты. Для разработки фронтенда используется Node.js (dev-сборка и локальный сервер). Бэкенд: Python + Flask как API и контейнер для расчётов и логики данных (на этапе разработки он запускается локально и даёт JSON-эндпоинты). Контроль версий — Git. На раннем этапе данные хранятся в JSON (mock), затем при переходе к постоянному хранению — СУБД (например PostgreSQL). Пока не рассматриваю развёртывание и инфраструктуру — задача сначала сделать надёжную работающую реализацию локально.

Глава 5 — Что я получу в итоге (артефакты)

Исходники фронтенда (Vue), сборка фронтенда для локального теста, исходники бэкенда (Flask) с API для получения/обновления данных и вызова расчётов, набор mock-данных в JSON, рабочая карта с маркерами и кликабельными карточками, интерфейс калькулятора и сравнительной таблицы, реализованные графики, README с инструкцией по локальному запуску и Git-репозиторий с историей коммитов.

Глава 6 — Требования к дальнейшему развитию и интеграции (без развёртывания сейчас)

Архитектура делается так, чтобы можно было в будущем без глобальной переработки подключать внешние источники данных, переносить вычисления на сервер или менять картографического провайдера. Формат обмена между фронтом и бэком должен быть чётко определён (JSON-эндпоинты), а все расчёты — модульными и переносимыми: формулы остаются внешними вводными от финансистов, я реализую их в виде функции/эндпоинта. На данном этапе приоритет — чистая, понятная кодовая база и согласованный формат данных; вопросы про контейнеры, nginx и продакшен-инфраструктуру оставляем на потом, после того как функционал и данные будут окончательно отлажены.

Короткая сводка

Я создаю расширяемый локально-работающий прототип цифрового двойника: фронтенд на Vue с Яндекс.Картами и Chart.js, бекенд на Flask с JSON-API, данные сначала в mock-JSON, позже в СУБД; в проекте есть карта с маркерами, карточки с документами и контактами, интерактивный финансовый калькулятор (NPV/IRR/payback и другие метрики по формулам финансистов), фильтры и сравнение проектов — всё в удобном виде для дальнейшего развития и интеграции.
