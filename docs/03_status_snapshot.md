# 03_status_snapshot.md

## Текущий срез по ветке `work`

Дата фиксации: автоматически по коммиту.

### По состоянию кода
- Backend уже реализует:
  - `GET /api/ping`
  - `GET /api/projects` (минимальные данные)
  - `GET /api/projects/<project_id>` (детали проекта)
- Источник данных: файловые JSON-моки в `data/projects/*/project.json`.
- В репозитории есть 10 мок-проектов.
- Frontend пока остаётся на шаблоне Vite + Vue и ещё не подключён к backend API.

### По роадмапу
Если ориентироваться строго на критерии в `docs/02_roadmap.md`:
- **Этап 1** (базовый каркас) — по сути закрыт.
- **Этап 2** (слой данных + подключение frontend к API) — **в процессе**:
  - backend-часть этапа уже сделана,
  - фронтенд-подключение и вывод списка проектов ещё не завершены.

### Что это значит practically
Сейчас проект находится на переходе от инфраструктуры к первому пользовательскому сценарию:
1. Данные уже читаются и отдаются сервером.
2. Следующий приоритет — заменить шаблонный UI на экран со списком проектов из API.
3. После этого можно переходить к карте (Этап 3).
